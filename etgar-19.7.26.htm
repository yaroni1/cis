Etgar 19.7.26: Problem and Solution

The Problem

Find the natural number solution for the equation combining a factorial and a quadratic term:

(n - 1)! + 1 = n2

The Solution

1. Algebraic Manipulation

  • Move 1 to the right side: (n - 1)! = n2 - 1
  • Apply the difference of squares formula, a2 - b2 = (a - b)(a + b), to the right side:
    (n - 1)! = (n - 1)(n + 1)
  • Express (n - 1)! as (n - 1) · (n - 2)!
  • Cancel out (n - 1) from both sides to simplify the equation to:
    (n - 2)! = n + 1

2. Variable Substitution

  • Let k = n - 2, which gives n = k + 2 and n + 1 = k + 3.
  • Substituting k into the equation yields:
    k! = k + 3

3. Factoring & Case Analysis

  • Rearrange to factor out k:
    k! - k = 3 ⇒ k · ((k - 1)! - 1) = 3
  • Since k must be an integer and 3 can only be factored into 1 × 3 or 3 × 1, test both cases:
    • Case 1 (k = 1): Gives (1 - 1)! - 1 = 3 ⇒ 0! - 1 = 3 ⇒ 0 = 3, which is impossible.
    • Case 2 (k = 3): Gives (3 - 1)! - 1 = 1 ⇒ 2! - 1 = 1, which holds true (1 = 1).

4. Final Answer & Verification

  • Since k = 3, n = k + 2 = 5.
  • Verification:
    • Left-Hand Side: (5 - 1)! + 1 = 4! + 1 = 24 + 1 = 25
    • Right-Hand Side: 52 = 25

Final Answer: n = 5
