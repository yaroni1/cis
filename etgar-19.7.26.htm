פתרון בעיה אתגר 19.7.26

הבעיה

למצוא את ערכו של n המקיים את המשוואה:

(n - 1)! + 1 = n²

הפתרון

שלב 1: פירוק אלגברי

מעבירים את 1 לאגף ימין:

(n - 1)! = n² - 1

לפי נוסחת הפרש ריבועים (n² - 1 = (n - 1)(n + 1)) ולפי הגדרת עצרת ((n - 1)! = (n - 1)(n - 2)!), המשוואה הופכת ל:

(n - 1)(n - 2)! = (n - 1)(n + 1)

מחלקים את שני האגפים ב-(n - 1) ומקבלים:

(n - 2)! = n + 1

שלב 2: הצבת משתנה עזר

נגדיר k = n - 2, ולכן n = k + 2 ו- n + 1 = k + 3.

נציב במשוואה ונקבל:

k! = k + 3

שלב 3: העברת אגפים ופירוק לגורמים

מעבירים את k לאגף שמאל:

k! - k = 3

מוציאים את k כגורם משותף (מכיוון ש- k! = k · (k - 1)!):

k · ((k - 1)! - 1) = 3

שלב 4: ניתוח אפשרויות

מכיוון ש-k מספר שלם ו-3 הוא מספר ראשוני, יש רק שתי אפשרויות למכפלת שני שלמים שתוצאתה 3:

  • אפשרות א': k = 1
    אם k = 1, הסוגריים שווים ל: (1 - 1)! - 1 = 0! - 1 = 1 - 1 = 0.
    המכפלה היא 1 · 0 = 0, וזה שונה מ-3. לכן אפשרות זו נפסלת.
  • אפשרות ב': k = 3
    אם k = 3, הסוגריים שווים ל: (3 - 1)! - 1 = 2! - 1 = 2 - 1 = 1.
    המכפלה היא 3 · 1 = 3. אפשרות זו נכונה!

שלב 5: מציאת n ובדיקה

מכיוון ש-k = 3, נחשב את n:

n = k + 2 = 3 + 2 = 5

בדיקה:

אגף שמאל: (5 - 1)! + 1 = 4! + 1 = 24 + 1 = 25

אגף ימין: 5² = 25

תשובה סופית: n = 5
